# @agiliza/config-tailwind

Unified Tailwind CSS preset for the Agiliza Network design system.

## Usage

```tsx
import { designTokens } from '@agiliza/config-tailwind'
```

## Design Tokens

- `colors.brand` — Primary, secondary, and accent brand colors
- `colors.neutral` — Dark theme neutral colors
- `colors.light` — Light theme colors
- `colors.semantic` — Success, warning, error, info
- `spacing` — 4px/8px grid-based spacing scale
- `borderRadius` — Consistent border radius tokens
- `shadows` — Elevation shadows
- `fonts` — Font family definitions
- `breakpoints` — Responsive breakpoints
- `touchTargetMin` — 44px minimum touch target
